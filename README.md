# 3Dblocks

立方体グリッドにブロックを積み、そろった列/面を消す 3D パズルゲーム。
スマホのブラウザ向け(three.js 使用)。基調はシングルブルーのミニマル(Apple 風)で、
色がつくのはブロックだけ。

ピースは3軸に広がる立体ポリキューブ。1マス〜直線・L・T・S/Z などの平面形に加え、
3方向コーナーやねじれ階段などの立体形、2×2×2・3×3 平面・3×2×2、
さらに 3×3×3(27マス)の大きな立方体まで「むずめ」の形も登場する。
各ピースは生成時にランダムな向き(3D回転)で現れ、パレットから 1 色をまとう。

## モード

タイトルで2つのモードを選べる(それぞれ別ランキング)。

| モード | グリッド | 消える条件 |
| --- | --- | --- |
| **ライン** | 5×5×5 | いずれかの軸で1列(5マス)そろうと、そのラインが消える。全ピース(3×3×3含む) |
| **プレーン** | 5×5×5 | 軸に垂直な1面(5×5=25マス)がすべて埋まると、その面が消える。面を埋めやすいよう大きすぎるピースは出ない |

グリッドサイズ・出題ピースの上限・クリア条件は [`js/config.js`](js/config.js) の `MODES` で調整できる。

## 遊び方

| 操作 | 動作 |
| --- | --- |
| 1本指ドラッグ(何も持っていない) | 視点の回転 |
| 1本指ドラッグ(かけらを持っている) | ピース移動。置ける場所に近づくと自動スナップして仮表示、指を離すと確定 |
| トレイまで指を戻す | 配置キャンセル(手持ちに戻る) |
| 2本指ピンチ | ズームイン / アウト |

- ピースは**床**か**すでに積まれたブロック**に接する場所にだけ置ける
- X・Y・Z いずれかの軸で1列そろうとそのラインが消える(複数同時でボーナス)
- **仮置き中は、消える列/面のブロックが金色に光って場所を予告**する
- 手持ち3つのどれも置けなくなったらゲームオーバー
- プレイ中は**左上のホームボタン**でタイトルへ戻れる
- **右下のすきまボタン(👁)**を押すと、埋まっているブロックはすべて白基調の半透明になり、
  空いているマスはすべて金色の半透明ブロックで示されるので、空間の抜けが一目で分かる
- **詰んでゲームオーバーになると、最後の手をどう置けば詰まなかったか**を、
  人が操作しているように**動画で自動再生**する(配給時点の盤面へ巻き戻し、ディーラーが
  保証した「3つとも置き切れる並び」を、ピースが上空から降りて置かれ、消去演出も本物で見せる)。
  再生中は元々埋まっていたブロックを**外枠だけ(元の色)**にして解の手だけ色付きで際立たせ、
  ゆっくり(0.5倍速)で見せる。再生中に**すきまボタン**を押すと、既存ブロックの表示を
  「外枠だけ ⇄ いつもの塗りつぶし」で切り替えられる(初回だけ吹き出しで案内)
- **ゲームオーバー画面**からは「もういちど / ホームへ戻る / ランキング」に進める
  (自己ベスト更新時は、なまえを記録してから)
- **中断復帰**: アプリを閉じても、次に開くとタイトルの「**つづきから**」で
  前回の盤面・スコアから再開できる(端末に自動セーブ)
- **自己ベストを更新したら、なまえを記録するまで次のゲームに進めない**

### ピース配給(スマートディーラー)

3つの手持ちは完全ランダムではなく、盤面をより賢く読んで配る:

- 「あと少しで消える列/面」にはまるピースを混ぜて気持ちよく。読みの精度を上げ、
  **一手で複数の列/面を同時に完成できる置き所**があるピースを特に高く評価する
  (ただし3つ全部は正解にせず、どれがどこにはまるかは自分で気づく余地を残す=
  良い手が出過ぎて単調にならない塩梅)
- さらに次の観点まで見て「いま欲しい一手」を勘ぐる:
  - **残り穴が少ないグループほど強く狙う**(完成まであと1マスの列に刺さる形は最優先)
  - **お膳立て**: 置いたあと「残り1〜2マス」になる置き所も評価(次の一手が見える)
  - **死に穴を作らない**: 置いた結果まわりを完全にふさがれて二度と埋められなくなる空きが
    できる置き方は大きく減点する(盤面をじわじわ殺す手を配らない)
  - **3つの狙いを散らす**: 3つとも同じ列を狙う組は、1つ置いた時点で残り2つが用済みに
    なって薄いので避ける
  - **苦しいときは逃げ道を混ぜる**: 盤面が詰まってくるほど「置ける場所が多いピース」を
    高く評価する(余裕があるときは効かせない)
  - この読みの重みは**モード別**。ライン(1列=5マス)は頻繁に消えるので狙いを強くしすぎると
    盤面が荒れて寿命が縮み、プレーン(1面=25マス)は強く狙わないとそもそも消えない。
    A/B計測で両立する値に調整してある(`js/dealer.js` の `READ`)
- **3つとも場に出た時点で、全部を置き切れる手順が最低1つ存在する**ことを解探索で
  保証(最適手順を選べば詰まない)。盤面がほぼ満杯のときは保証なしのフォールバック
- さらに、盤面が埋まってきたら**「置き切れる並びの通り数」が少ない=最適解が絞れる
  締まった組**を優先して配る。序盤のスカスカな盤面では素直に軽く配る
- **ごくたまに、盤面をまるごと空にできる「全消し」の当たり手**を配って最大のご褒美に。
  さらに**たまに大きく消せる(面1枚・複数ライン)当たり手**も(頻度は `js/dealer.js` の
  `FULLCLEAR` などの定数でモード別に調整可能)。
- 全消しは**偶然を待つのではなく逆算して構成する**。「残っているブロックを覆う線/面」を選び、
  その空き部分をちょうど3ピースで敷き詰められるかを解く(`buildClearAllTrio`)。
  空きが低い位置=支えのある所になる覆いを優先する(宙に浮いた空きは置けないため)。
  ただし全消しは幾何条件が厳しく、**残りブロックが薄い時にしか成立しない**
  (計測: 残26マス超はほぼ0%、残16マス以下なら3〜5割)。そのため抽選する帯を
  薄い盤面に絞り、そこでは高確率で狙いにいく(厚い盤面では探索もしないので軽い)
- **全消しチャンスの告知**: いまの手札で盤面を空にできる並びが存在する間は、
  トレイの上に**「✦ 全消しチャンス ✦」**の金色バナーが出続け、トレイも金色に光る
  (到来した瞬間だけ専用の音と振動)。ディーラーが仕込んだチャンスも、たまたま成立した
  チャンスも同じように拾う。**1手ごとに判定し直す**ので、置き方を誤ってチャンスが
  消えたら告知もすぐ引っ込む(嘘の告知はしない)
- 出題ピースの平均体積をさらに大きめ(約6.6マス)に寄せ、見た目の歯ごたえを上げている。
  その分の詰みは上の全消し・大消しのご褒美と置き切り保証で救済する
- **段階的な全消し(クリアラン)**: 1手の3ピースで空にできる盤面はごく限られるので、
  そこに届かない場面では**「置けば確実にブロックが減る手」を配り続けて、何手かかけて
  空へ向かわせる**。流れに入っている間はバナーが**「✦ 全消しへ あと◯個 ✦」**に変わり、
  残りが減っていくのが見える。減らせない場面では「完成まであと何マス」を縮める
  仕込みの手で繋ぎ、それでも記録を更新できない手が続いたら流れは終わる
  (だらだら続いて簡単になりすぎないように)。空にできたら**全消しボーナス**が入る
- **たまに難問**: ときどき「**最適解(と、せいぜいもう1通り)しか正解が無い**」組を配る。
  外すと詰むので、置き場所をよく考える必要がある(ライン中心・出過ぎないよう控えめ)。
  通り数 0(配られた時点で詰み)の組は絶対に配らないので、**正解は必ず存在する**。
  外して詰んでも、いつもどおり「こう置けばよかった」の自動再生で答えが見られる。
  頻度は `js/dealer.js` の `TIGHT_PROB` / `TIGHT_MAX_WAYS` で調整可能
- **good エフェクト**: ディーラーが想定する最適解と同じ位置にピースを置けたときだけ、
  その場所に「good」が弾ける(音つき)。この最適解は**「いちばん点が高くなる手順」**
  (消去・複数同時・コンボ・全消しボーナスまで数えた上での最善)なので、
  **ブロックが消える気持ちいい置き所が正解**になる。1手ごとに引き直すため、
  途中で違う置き方をしても、そこからの最善手に対して good が出る

## 動かし方

ビルド不要の静的サイトです。そのままホスティングするだけで動きます。

```bash
# ローカルで試す
python3 -m http.server 8000
# → スマホと同じ Wi-Fi なら http://<PCのIP>:8000 で実機確認できる
```

GitHub Pages なら: リポジトリの Settings → Pages → Branch にこのブランチを指定するだけ。

## スマホアプリのように使う (PWA)

- **アプリ内ブラウザからの脱出**: LINE 等のアプリ内ブラウザで開くと、LINE は公式の
  `openExternalBrowser=1` で自動的に Safari / Chrome へ飛ぶ。抜けられない環境
  (iOS の Instagram 等)では「ブラウザで開く / URLをコピー」の案内を表示する。
- **全画面表示**: `manifest.json`(`display: fullscreen`)と Apple 用メタタグにより、
  ホーム画面から起動するとブラウザのバーが消えて全画面になる。
- **ホーム画面に追加**: マニフェスト + アイコン + Service Worker(`sw.js`)対応。
  iOS は Safari の共有 →「ホーム画面に追加」、Android は Chrome のインストール案内から。
  Service Worker がシェルをキャッシュするので2回目以降はオフラインでも起動する。
- **アプリアイコン**: `icons/` に 180/192/512(＋マスカブル)を用意。ブランドのブルー地に
  アイソメトリックの3色ブロック。差し替えるときは同じサイズの PNG を置くだけ。

> 注意: PWA 機能(Service Worker / インストール)は **HTTPS**(または localhost)で動く。
> GitHub Pages は HTTPS なのでそのまま有効。ファイルを更新したら `sw.js` の
> `VERSION` を上げるとキャッシュが更新される。

## バージョン

アプリのバージョンは [`js/config.js`](js/config.js) の `APP_VERSION` が唯一の基準で、
タイトル画面の右下に「v◯.◯」と表示される。**マージ(リリース)のたびに +0.1** し、
同時に `sw.js` の `VERSION`(キャッシュ名)も同じ番号へ更新してキャッシュを入れ替える。
現在は **2.8**。

## オンライン世界ランキングを有効にする(約5分)

ランキングは Firebase Realtime Database の REST API を SDK なしで直接使います。
未設定の間は自動的に「この端末のランキング」のみで動作します。

1. [Firebase Console](https://console.firebase.google.com/) で無料プロジェクトを作成
2. 「構築 → Realtime Database」→「データベースを作成」(ロケーションはどこでも可)
3. セキュリティルールを次のように設定:

   ```json
   {
     "rules": {
       "blocks3d": {
         "v1": {
           ".read": true,
           ".indexOn": ["s"],
           "$entry": {
             ".write": "!data.exists()",
             ".validate": "newData.hasChildren(['n','s','t']) && newData.child('n').isString() && newData.child('n').val().length <= 12 && newData.child('s').isNumber() && newData.child('s').val() >= 0"
           }
         }
       }
     }
   }
   ```

   (追記のみ許可・改ざん防止のバリデーション付き。カジュアルなランキング用途を想定)

4. データベースの URL(`https://xxxx-default-rtdb.….firebasedatabase.app` の形式)をコピーし、
   [`js/config.js`](js/config.js) の `RANKING.endpoint` に貼り付ける:

   ```js
   export const RANKING = {
     endpoint: "https://xxxx-default-rtdb.asia-southeast1.firebasedatabase.app",
     path: "blocks3d/v1",
     limit: 100,
   };
   ```

これだけで、ゲームオーバー画面から世界ランキングへの登録と閲覧ができるようになります。
ライン/プレーンの2モードは**同じ保存先(`blocks3d/v1`)に mode フィールド付きで記録**し、
表示時にモードで絞り込むので、上記ルールのままで両モードの別ランキングが動きます。

> **注意**: クライアントのみで完結する構成のため、本気の不正対策はできません。
> 友達や世界のプレイヤーとゆるく競うカジュアルランキングとして使ってください。

## 構成

```
index.html        エントリ(UI マークアップ + アプリ内ブラウザ脱出 + PWA登録)
css/style.css     ビジュアルテーマ
manifest.json     PWA マニフェスト(全画面・ホーム画面追加・アイコン)
sw.js             Service Worker(インストール対応 + オフラインキャッシュ)
icons/            アプリアイコン(180/192/512・マスカブル・favicon)
js/config.js      グリッド・モード・色・スコア・ランキング設定
js/shapes.js      3D形状(立体ポリキューブ)の定義と生成
js/board.js       盤面ロジック(配置判定・ライン/面検出)
js/audio.js       WebAudio シンセ効果音
js/ranking.js     世界ランキング(Firebase REST)+端末内ランキング(モード別)
js/game.js        three.js シーン・操作・演出・ゲームフロー
```
